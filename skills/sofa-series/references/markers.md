# Разметка заставок и титров

## Порядок проверки

1. Получи ID сериала через `list`, создай черновик командой `markers init <ID>`. Она заполняет сведения о реальных файлах и сохраняет уже существующие записи.
2. Для каждого файла прочитай длительность и главы через `ffprobe`. Название главы — подсказка, а не подтверждение границы.
3. Извлеки обзорные кадры начала и конца. Например:

   ```sh
   python3 sofa.py frames show-ID s01e01 --times 0:240:15 --output work/opening.jpg
   python3 sofa.py frames show-ID s01e01 --times 3000:3300:10 --output work/ending.jpg
   ```

   Время в этих примерах условное: подставь диапазоны внутри длительности файла. Команда принимает секунды через запятую и диапазоны `начало:конец:шаг` с исключённым концом. Максимум — 100 кадров за вызов. Для близкой проверки используй шаг 1 секунду и `--width 640`.
4. **Посмотри полученные изображения.** Найди соседние кадры до и после перехода. При неясном чёрном кадре проверь также звук/субтитры: темнота не означает отсутствие сюжетной сцены. Не переноси тайминги между сериями без проверки.
5. Сохрани сцену или пересказ перед заставкой. Прыжок должен начинаться внутри самой заставки и заканчиваться примерно за 3 секунды до сюжета.
6. Просмотри хвост серии до конца: сцены между титрами и после них, эпилоги, анонсы. Если после первых титров есть сюжет, ставь переход на последующие **финальные** титры после этой сцены. Если безопасной границы нет, оставь `credits: null`.
7. Сохрани подтверждённые времена и выполни `markers validate <ID>`. Проверь `marked` в статусе текущей серии либо сопоставь все записи каталога с валидатором. Не запускай чужую серию ради проверки, пока пользователь смотрит.

## Сохранение

```sh
python3 sofa.py markers set show-ID s01e01 \
  --intro 20 127 130 --credits 3210 3212 \
  --notes "Проверены кадры 19–21, 126–131, 3209–3213 и весь хвост; сюжетных сцен после титров нет"
```

Это пример формы команды, **не готовые тайминги**. Пропущенный `--intro` или `--credits` записывает `null`: в заметке объясни, отсутствует ли сегмент или почему его нельзя безопасно пропускать. Команда не доказывает корректность разметки — её подтверждает визуальная проверка агента.

`markers.json` находится прямо в папке сериала. Версия формата — `1`. В `episodes` ключами служат `s01e01`, `s01e02` и т. п., без ID сериала.

| Поле записи | Значение |
| --- | --- |
| `file` | Относительный путь внутри папки сериала, с `/` |
| `size`, `mtime` | Размер в байтах и время изменения в целых Unix-секундах |
| `duration` | Длительность файла в секундах |
| `verified` | `true` только после проверки этого файла |
| `intro.start` | Начало безопасного для пропуска участка заставки |
| `intro.skipTo` | Место перехода, сохраняющее конец заставки |
| `intro.finish` | Граница заставки и сюжетной части |
| `credits.start` | Начало финальных титров после всех сюжетных сцен |
| `credits.nextAt` | Когда открыть следующую доступную серию |
| `review` | Способ и краткие заметки о проверке |

Ограничения: `0 ≤ start < skipTo < finish < duration`; `finish − skipTo ≤ 5`; `credits.start ≤ nextAt < duration`; `nextAt − credits.start ≤ 5`. Если есть оба сегмента, заставка должна закончиться до титров. Отсутствующий сегмент — JSON `null`.

Путь, размер, mtime и длительность привязывают разметку к конкретному файлу. После замены релиза старые тайминги не применяются. Проверенные заставки и финальные титры не считаются непросмотренным сюжетом; настоящие просмотренные интервалы при этом сохраняются.

## Когда изменения включаются

В установленном Sofa Remote 1.x манифест перечитывается примерно раз в 1–2 секунды. Перезапуск VLC ради `markers.json` или добавления сериала не требуется. На паузе автоматика ничего не делает. Уже выполненный автопропуск в той же сессии серии не повторяется при ручном возвращении назад.

Если установлен старый пульт без поддержки каталогов или подготовлен новый Lua-код, потребуется один полный выход и запуск VLC. Статический интерфейс новой версии обновляется при перезагрузке страницы. Дай ссылку и отдельно укажи, что реально работает сейчас.
