# Сериалы для диванного пульта

Сначала дай возможность смотреть. Затем разметь автоматические переходы.
Команды ниже выполняй через `python3 <папка скилла>/scripts/sofa.py`.

## 1. Подготовь просмотр

- Прими локальный путь к сериалу или коллекции. Если папка лишь прикреплена в чате, найди её доступный локальный путь; не выдумывай его.
- Запусти `doctor`, затем `scan <папка> --durations`. Проверь сезоны, серии, пропущенные файлы и дубликаты. Не добавляй отсутствующие серии и не угадывай неоднозначные номера.
- Добавь сериал: `add <папка> --title "Название"`. Для отдельных сериалов в дочерних папках используй `add <папка> --collection`. Существующие ID и прогресс сохраняй.
- Если пульт ещё не установлен, установи зависимости и выполни `install`, когда VLC закрыт. Открой VLC после первой установки. **Текущий просмотр не останавливай и не перематывай.** При работающем настроенном пульте обновление можно подготовить через `install --stage`; честно укажи, если нужен перезапуск.
- Проверь `doctor --check-auth`, список сериалов и серии через API. Проверь HTTP по адресу локальной сети; при доступном телефоне — также с телефона. Локальный ответ сам по себе не доказывает доступность по Wi-Fi.
- **Сообщи сразу:** какие сериалы и сколько серий доступны, ссылку на пульт и результат проверки. Пароль можно получить командой `access`. Не откладывай это сообщение до завершения разметки.

## 2. Разметь автоматические переходы

- После готовности каталога продолжи работу в том же чате. Прочитай [правила разметки](references/markers.md).
- Используй `ffprobe` и `frames` для извлечения кадров из файлов. Не управляй текущим VLC и не используй интерфейс компьютера для поиска границ.
- Проверь **каждую серию**, включая сцены до заставки и после титров. Общая длительность заставки — только подсказка. Сохрани примерно 3 секунды её конца и 2 секунды начала финальных титров; допустимый запас — до 5 секунд. Сюжет важнее экономии времени.
- Сохрани `markers.json` прямо в папке каждого сериала. Ставь `verified: true` только после визуальной проверки конкретного файла. Неуверенные границы оставляй неподтверждёнными; для отсутствующего сегмента используй `null` и поясни причину.
- Выполни `markers validate <ID>` и проверь, что работающий пульт подхватил разметку. Новая версия читает её автоматически; перезапуск ради JSON не нужен.
- **Сообщи итог:** проверено N из M серий, где лежат манифесты, что осталось неоднозначным и активна ли автоматика. Не называй подготовленное обновление уже работающим.
