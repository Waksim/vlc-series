# Работа с Sofa Remote

- Это локальный пульт для VLC 3.x/macOS: Lua-сервер и трекер внутри VLC, обычный JS в браузере, Python CLI, маленький CoreAudio-помощник. Начни с `README.md` и `docs/architecture.md`.
- Для добавления и разметки сериалов по явному запросу используй `skills/sofa-series/SKILL.md`. Обычная доработка проекта не требует загружать этот скилл.
- Не перезапускай основной VLC, не меняй его позицию, громкость или аудиовыход ради теста. Используй изолированный тест с синтетическим видео; завершай только PID, который сам запустил.
- Сохраняй ID сериалов и историю. Перемотки не являются просмотром. Автопереход не должен уходить в другой сериал. Таймлайн в браузере не интерактивный.
- Проверенная разметка привязана к относительному пути, размеру, mtime и длительности. Не копируй тайминги на другой релиз. `markers.json` лежит в папке сериала и перечитывается без перезапуска.
- Не коммить конфигурацию установленного профиля, пароли, токены, пути пользователя, его историю, видео или кадры. Публичные примеры и тесты должны быть синтетическими.
- Выполни подходящие проверки из README. При изменении API/парсера проверь обе реализации и сценарии нескольких сериалов; при UI-изменениях проверь мобильный экран. Укажи, какие проверки реально выполнены.
- Если новый Lua-код только подготовлен через `install --stage`, сообщи о необходимости следующего полного перезапуска. Не называй подготовленную версию активной.
